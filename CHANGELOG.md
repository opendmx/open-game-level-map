# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-12-22

### Added
- Initial release of Game Level Map web component
- Four built-in themes: Adventure, Space, Fantasy, and Retro
- Three layout options: Linear, Circular, and Branching
- Multiple path styles: Curved, Straight, and Zigzag
- Three size options: Small, Medium, and Large
- Interactive level markers with click events
- Progress tracking with visual indicators
- Custom level names support
- Animated transitions and effects
- Progress bar display
- Comic-style visual design
- Responsive design for mobile devices
- Framework-agnostic implementation
- Comprehensive documentation and examples
- Interactive demo website
- Full TypeScript-style JSDoc comments
- Web Components standard compliance

### Features
- **Customizable Configuration**: All aspects configurable via HTML attributes or JavaScript API
- **Event System**: Level click events for interaction handling
- **Accessibility**: Built with web standards and accessibility in mind
- **Performance**: Efficient rendering with minimal DOM manipulation
- **Browser Support**: Works in all modern browsers supporting Web Components

### Documentation
- Complete API documentation
- Usage examples for React, Vue, Angular, and vanilla JavaScript
- Interactive demo with live configuration
- Comprehensive README with quick start guide
