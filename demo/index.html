Features

  • 🎨 Comic-style Design: Colorful, fun graphics with animations
  • 📱 Responsive: Works on all screen sizes
  • ⚙️ Highly Configurable: Customize levels, colors, sizes, and more
  • 🎯 Interactive: Click events for level selection
  • ✨ Animated: Smooth transitions and eye-catching effects
  • 🔧 Easy Integration: Simple HTML custom element
  • 📊 Progress Tracking: Visual representation of game progress
  • 🎮 Game-Ready: Perfect for web games and educational apps
