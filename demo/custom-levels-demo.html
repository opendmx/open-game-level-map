Configuration Examples

JavaScript API

const levelMap = document.querySelector('game-level-map'); // Set individual level configuration levelMap.setLevelConfig(1, { shape: 'star', icon: '🌟', size: 50, color: '#FFD700', animation: 'bounce', text: 'Start', onClick: (data) => console.log('Level clicked:', data) }); // Set multiple level configurations at once levelMap.setLevelConfigs({ 1: { shape: 'circle', icon: '🏠' }, 2: { shape: 'square', icon: '🌲' }, 3: { shape: 'diamond', icon: '⛰️' }, 4: { shape: 'hexagon', icon: '🏰' }, 5: { shape: 'star', icon: '👑' } });

HTML Attribute (JSON)

<game-level-map levels="5" current-level="3" level-config='{ "1": {"shape": "star", "icon": "🌟"}, "2": {"shape": "square", "color": "#FF6B6B"}, "3": {"shape": "diamond", "animation": "pulse-large"} }'> </game-level-map>

Available Options

  • shape: 'circle', 'square', 'diamond', 'hexagon', 'star'
  • size: Number (in pixels)
  • icon: String (emoji or icon character)
  • text: String (custom text instead of level number)
  • color: String (hex color code)
  • animation: 'bounce', 'spin', 'pulse-large', 'wiggle'
  • onClick: Function (custom click handler)
  • hideCompletionStar: Boolean (hide star on completed levels)
